# PMP Exam Prep — Interactive Practice Tool

A fully self-contained, browser-based **PMP certification exam preparation tool** with 200 practice questions, live scoring, and a key concepts cheat sheet.

## What It Does

Helps PMP exam candidates practice questions across all three ECO 2021 domains, track their score in real time, filter by domain or difficulty, and review key concepts — all without any login or account.

## Key Features

- **200 PMP practice questions** mapped to ECO 2021 domains:
  - People — 42%
  - Process — 50%
  - Business Environment — 8%
- **Click-to-reveal answers** with detailed explanations for each question
- **Live score tracker** — running score and per-domain breakdown updated as you answer
- **Search by keyword** — find questions on any specific topic instantly
- **Filter by domain and difficulty** — focus your study session
- **Key Concepts cheat sheet** — 16 essential PMP topics summarized
- **Dark / Light mode** toggle — study comfortably in any environment
- **Add custom questions** — via UI (current session) or `questions.js` (permanently)
- **Zero dependencies** — runs entirely in the browser, no install needed
